# customer-segmentation-study-for-a-real-e

> source: synthetic | persona: data | project: data-p20

Built for a real estate client. The problem: a retailer sent the same email to every customer.

## Features
- Wrote window-function queries over millions of rows
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Statistics, plus the usual supporting libraries.

## Results
In production this lifted email revenue 62% using segments.
