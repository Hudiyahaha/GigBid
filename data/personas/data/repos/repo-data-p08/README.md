# marketing-attribution-model-v2-gaming

> source: synthetic | persona: data | project: data-p08

Built for a gaming client. The problem: a marketing team could not tell which channel drove sales.

## Features
- Shared free self-serve marketing dashboards
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Google Analytics 4, plus the usual supporting libraries.

## Results
In production this re-allocated 38% of ad spend to better channels.
