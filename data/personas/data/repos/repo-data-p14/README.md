# crm-data-clean-up-v2-healthcare

> source: synthetic | persona: data | project: data-p14

- Built pivot-table workbooks with lookups for the finance team
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Excel, plus the usual supporting libraries.

## Results
In production this merged 12000 duplicate records.
