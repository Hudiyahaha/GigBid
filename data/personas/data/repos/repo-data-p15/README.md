# marketing-attribution-model-for-a-retail

> source: synthetic | persona: data | project: data-p15

Built for a retail client. The problem: a marketing team could not tell which channel drove sales.

## Features
- Wrote window-function queries over millions of rows
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly BigQuery, plus the usual supporting libraries.

## Results
In production this re-allocated 61% of ad spend to better channels.
