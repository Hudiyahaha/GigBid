# Pricing experiment analysis v2 (logistics)

**Client:** Peakwave Ventures (synthetic) (logistics) | **Duration:** 3 weeks | **Year:** 2022

## The problem
The client came to me because an app changed prices without knowing if it helped.

## What I did
- Designed controlled experiments and computed significance and power, using A/B testing.
- Ran regressions and hypothesis tests with confidence intervals, using Statistics.
- Used pandas for the core of the solution.
- Made charts that explained the numbers at a glance.

## Result
The project found a price that lifted conversion 28% within the first months after launch.

Write the runbook earlier.
