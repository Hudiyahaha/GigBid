# CRM data clean-up

**Client:** Deltaleaf Studio (synthetic) (e-commerce) | **Duration:** 11 weeks | **Year:** 2026

## The problem
The client came to me because a sales team's CRM had thousands of duplicate contacts.

## What I did
- Deduplicated and standardised inconsistent records, using Data cleaning.
- Cleaned and reshaped messy tables in dataframes, using pandas.
- Built pivot-table workbooks with lookups for the finance team, using Excel.
- Scripted the whole pipeline end to end.

## Result
The project merged 12000 duplicate records within the first months after launch.

Agree on evaluation metrics before building.
