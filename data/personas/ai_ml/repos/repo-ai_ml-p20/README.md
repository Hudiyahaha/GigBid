# semantic-product-search-for-a-non-profit

> source: synthetic | persona: ai_ml | project: ai_ml-p20

Built for a non-profit client. The problem: an online shop's keyword search missed obvious matches.

## Features
- Built an in-process approximate nearest-neighbour index
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly LoRA fine-tuning, plus the usual supporting libraries.

## Results
In production this lifted search click-through by 53%.
