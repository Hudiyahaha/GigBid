# model-serving-platform

> source: synthetic | persona: ai_ml | project: ai_ml-p05

Built for a SaaS client. The problem: data scientists shipped models by emailing pickle files.

## Features
- Deployed the model to a managed cloud inference endpoint
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly FastAPI, plus the usual supporting libraries.

## Results
In production this cut model release time from weeks to 6 days.
