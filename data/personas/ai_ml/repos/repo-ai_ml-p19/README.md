# model-serving-platform-for-a-travel-clie

> source: synthetic | persona: ai_ml | project: ai_ml-p19

Built for a travel client. The problem: data scientists shipped models by emailing pickle files.

## Features
- Exposed the model behind an async typed http service
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly MLflow, plus the usual supporting libraries.

## Results
In production this cut model release time from weeks to 2 days.
