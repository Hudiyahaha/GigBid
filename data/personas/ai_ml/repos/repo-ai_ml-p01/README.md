# support-ticket-triage-agent

> source: synthetic | persona: ai_ml | project: ai_ml-p01

Built for a education client. The problem: a support team was manually routing thousands of tickets a week.

## Features
- Processed free-text customer messages at scale
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly LangGraph, plus the usual supporting libraries.

## Results
In production this auto-routed 33% of tickets correctly.
