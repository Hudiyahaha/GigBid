# Model serving platform v2 (e-commerce)

**Client:** Atlasline Ventures (synthetic) (e-commerce) | **Duration:** 11 weeks | **Year:** 2023

## The problem
The client came to me because data scientists shipped models by emailing pickle files.

## What I did
- Tracked every experiment's parameters, metrics and model artefacts, using MLflow.
- Exposed the model behind an async typed HTTP service, using FastAPI.
- Deployed the model to a managed cloud inference endpoint.
- Scripted the whole pipeline end to end.

## Result
The project cut model release time from weeks to 5 days within the first months after launch.

## What I would do differently
Write the runbook earlier.
