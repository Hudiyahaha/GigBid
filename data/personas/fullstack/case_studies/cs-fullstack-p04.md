# Serverless image service

**Client:** Ironleaf Learning (synthetic) (insurance) | **Duration:** 11 weeks | **Year:** 2021

## The problem
The client came to me because a media site's image resizing server kept crashing under load.

## What I did
- Ran the backend as serverless functions, using AWS Lambda.
- Ran the backend on a JavaScript server runtime.
- Kept the whole codebase strictly typed.

## Result
The project cut hosting cost by 30% within the first months after launch.

## What I would do differently
Add monitoring from day one.
