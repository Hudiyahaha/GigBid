# Multi-vendor marketplace

**Client:** Swiftstone Capital (synthetic) (logistics) | **Duration:** 7 weeks | **Year:** 2023

## The problem
The client came to me because artisans needed a shared store with separate payouts.

## What I did
- Took card payments and subscriptions with webhooks, using Stripe.
- Wrote minimal middleware-based HTTP routes, using Express.
- Used file-based routing with server-side rendering.
- Stored flexible JSON documents in a document database.

## Result
The project onboarded 55 vendors in two months within the first months after launch.

## What I would do differently
Write the runbook earlier.
