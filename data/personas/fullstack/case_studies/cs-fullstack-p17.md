# Internal admin dashboard for a travel client

**Client:** Lumenpoint Retail (synthetic) (travel) | **Duration:** 10 weeks | **Year:** 2025

## The problem
The client came to me because operations staff edited production data directly in SQL.

## What I did
- Kept the whole codebase strictly typed, using TypeScript.
- Styled everything with utility classes, using Tailwind CSS.
- Exposed a single typed query endpoint with resolvers, using GraphQL.
- Structured the backend in modules with dependency injection, using NestJS.

## Result
The project removed 29 manual SQL edits a week within the first months after launch.

## What I would do differently
Involve end users in week one.
