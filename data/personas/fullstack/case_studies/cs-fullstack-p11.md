# Serverless image service v2 (real estate)

**Client:** Brightbridge Group (synthetic) (real estate) | **Duration:** 11 weeks | **Year:** 2022

## The problem
The client came to me because a media site's image resizing server kept crashing under load.

## What I did
- Ran the backend on a JavaScript server runtime, using Node.js.
- Used TypeScript for the core of the solution.
- Used React for the core of the solution.

## Result
The project cut hosting cost by 43% within the first months after launch.

## What I would do differently
Write the runbook earlier.
