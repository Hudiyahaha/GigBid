# Internal admin dashboard

**Client:** Quartzfield Retail (synthetic) (travel) | **Duration:** 15 weeks | **Year:** 2025

## The problem
The client came to me because operations staff edited production data directly in SQL.

## What I did
- Used Tailwind CSS for the core of the solution.
- Built the interface from reusable stateful components with hooks.
- Kept the whole codebase strictly typed.
- Exposed a single typed query endpoint with resolvers.

## Result
The project removed 71 manual SQL edits a week within the first months after launch.

## What I would do differently
Agree on evaluation metrics before building.
