# Multi-vendor marketplace v2 (travel)

**Client:** Blueline Travel (synthetic) (travel) | **Duration:** 8 weeks | **Year:** 2025

## The problem
The client came to me because artisans needed a shared store with separate payouts.

## What I did
- Stored flexible JSON documents in a document database, using MongoDB.
- Used Stripe for the core of the solution.
- Used TypeScript for the core of the solution.
- Used file-based routing with server-side rendering.

## Result
The project onboarded 76 vendors in two months within the first months after launch.

## What I would do differently
Add monitoring from day one.
