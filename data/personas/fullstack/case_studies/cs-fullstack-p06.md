# E2E test and CI overhaul

**Client:** Clearfield Logistics (synthetic) (insurance) | **Duration:** 3 weeks | **Year:** 2026

## The problem
The client came to me because a SaaS team shipped regressions every release.

## What I did
- Covered the critical user journeys with browser end-to-end tests, using Playwright.
- Used GitHub Actions for the core of the solution.
- Used TypeScript for the core of the solution.
- Packaged everything into reproducible container images.

## Result
The project cut escaped bugs by 44% within the first months after launch.

## What I would do differently
Add monitoring from day one.
