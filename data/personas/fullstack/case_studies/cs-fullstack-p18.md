# Serverless image service for a travel client

**Client:** Maplestone Ventures (synthetic) (travel) | **Duration:** 7 weeks | **Year:** 2024

## The problem
The client came to me because a media site's image resizing server kept crashing under load.

## What I did
- Used Node.js for the core of the solution.
- Covered the critical user journeys with browser end-to-end tests, using Playwright.
- Ran the backend as serverless functions.

## Result
The project cut hosting cost by 47% within the first months after launch.

## What I would do differently
Write the runbook earlier.
