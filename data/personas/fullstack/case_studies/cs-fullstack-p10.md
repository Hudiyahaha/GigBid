# Internal admin dashboard v2 (healthcare)

**Client:** Atlasleaf Media (synthetic) (healthcare) | **Duration:** 15 weeks | **Year:** 2022

## The problem
The client came to me because operations staff edited production data directly in SQL.

## What I did
- Styled everything with utility classes, using Tailwind CSS.
- Built the interface from reusable stateful components with hooks.
- Kept the whole codebase strictly typed.
- Stored flexible JSON documents in a document database.

## Result
The project removed 47 manual SQL edits a week within the first months after launch.

## What I would do differently
Add monitoring from day one.
