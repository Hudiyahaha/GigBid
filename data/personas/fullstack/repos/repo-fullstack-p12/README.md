# fitness-tracking-pwa-v2-non-profit

> source: synthetic | persona: fullstack | project: fullstack-p12

Built for a non-profit client. The problem: a gym wanted members to log workouts from their phones.

## Features
- Styled everything with utility classes
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Authentication, plus the usual supporting libraries.

## Results
In production this reached 1200 weekly active users.
