# internal-admin-dashboard

> source: synthetic | persona: fullstack | project: fullstack-p03

Built for a travel client. The problem: operations staff edited production data directly in SQL.

## Features
- Exposed a single typed query endpoint with resolvers
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Tailwind CSS, plus the usual supporting libraries.

## Results
In production this removed 71 manual SQL edits a week.
