# logistics-tracking-api

> source: synthetic | persona: fullstack | project: fullstack-p02

Built for a healthcare client. The problem: dispatchers could not see where trucks were in real time.

## Features
- Designed resource-oriented http endpoints with pagination
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly NestJS, plus the usual supporting libraries.

## Results
In production this served 2500 requests per second at p95 under 120 ms.
