# e2e-test-and-ci-overhaul-for-a-saas-clie

> source: synthetic | persona: fullstack | project: fullstack-p20

Built for a SaaS client. The problem: a SaaS team shipped regressions every release.

## Features
- Covered the critical user journeys with browser end-to-end tests
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Playwright, plus the usual supporting libraries.

## Results
In production this cut escaped bugs by 18%.
