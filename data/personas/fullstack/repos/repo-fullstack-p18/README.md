# serverless-image-service-for-a-travel-cl

> source: synthetic | persona: fullstack | project: fullstack-p18

Built for a travel client. The problem: a media site's image resizing server kept crashing under load.

## Features
- Covered the critical user journeys with browser end-to-end tests
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Node.js, plus the usual supporting libraries.

## Results
In production this cut hosting cost by 47%.
