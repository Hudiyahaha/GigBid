# fitness-tracking-pwa-for-a-education-cli

> source: synthetic | persona: fullstack | project: fullstack-p19

Built for a education client. The problem: a gym wanted members to log workouts from their phones.

## Features
- Used a hosted backend for auth and realtime data
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Redis, plus the usual supporting libraries.

## Results
In production this reached 4000 weekly active users.
