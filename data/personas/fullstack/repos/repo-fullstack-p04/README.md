# serverless-image-service

> source: synthetic | persona: fullstack | project: fullstack-p04

Built for a insurance client. The problem: a media site's image resizing server kept crashing under load.

## Features
- Kept the whole codebase strictly typed
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly TypeScript, plus the usual supporting libraries.

## Results
In production this cut hosting cost by 30%.
