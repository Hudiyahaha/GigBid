# e2e-test-and-ci-overhaul

> source: synthetic | persona: fullstack | project: fullstack-p06

- Ran lint, tests and deploys automatically on every pull request
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Docker, plus the usual supporting libraries.

## Results
In production this cut escaped bugs by 44%.
