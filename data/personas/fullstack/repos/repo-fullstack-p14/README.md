# multi-vendor-marketplace-v2-travel

> source: synthetic | persona: fullstack | project: fullstack-p14

Built for a travel client. The problem: artisans needed a shared store with separate payouts.

## Features
- Stored flexible json documents in a document database
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly MongoDB, plus the usual supporting libraries.

## Results
In production this onboarded 76 vendors in two months.
