# fitness-tracking-pwa

> source: synthetic | persona: fullstack | project: fullstack-p05

Built for a media client. The problem: a gym wanted members to log workouts from their phones.

## Features
- Built the interface from reusable stateful components with hooks
- Configuration through environment variables
- Unit tests and a small demo dataset

## Stack
Mostly Authentication, plus the usual supporting libraries.

## Results
In production this reached 1200 weekly active users.
